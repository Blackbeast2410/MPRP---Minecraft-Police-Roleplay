# Lighting Packages

Lighting packages describe how a vehicle's physical light nodes map to logical light groups.

Example physical nodes:

```text
FL_01
FR_01
GRL_01
GRR_01
TD_01
AL_01
```

The package can define:

- Light groups
- Light colors
- Pattern assignments
- Intensity
- Node mappings
- Traffic Advisor mappings
- Take-down mapping
- Alley-light mapping

Lighting packages should remain independent from the vehicle entity implementation.
