# Development Workflow

Every significant task follows:

```text
Understand requirement
→ Inspect repository
→ Read docs
→ Identify affected systems
→ Plan
→ Implement smallest appropriate change
→ Build
→ Test
→ Review diff
→ Update docs
→ Commit
```

## AI Development

Recommended responsibilities:

- ChatGPT: architecture, design, teaching, review, task breakdown
- Codex: implementation, repository edits, Gradle execution, tests, debugging
- Optional second reviewer: independent code review

Agents must inspect before editing and must not fabricate existing APIs.
