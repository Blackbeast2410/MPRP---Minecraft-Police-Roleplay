# ADR-0006: MPRP Permissions Are Separate From Minecraft OP

## Status

Accepted

## Date

2026-09-25

## Context

Minecraft operator permissions are not equivalent to police roleplay permissions.

MPRP requires roles such as officer, dispatcher, supervisor, command, records, and evidence staff.

## Decision

MPRP will maintain its own role and permission system.

Minecraft OP may still be used for administrative/moderation purposes, but it must not be the primary mechanism for ordinary MPRP gameplay authorization.

Permissions should be explicit and preferably data-driven.

## Consequences

### Benefits

- Correct roleplay authorization
- Flexible department configurations
- Clear separation between server administration and in-game roles

### Costs

- Additional permission infrastructure
- Permission checks must be implemented consistently
