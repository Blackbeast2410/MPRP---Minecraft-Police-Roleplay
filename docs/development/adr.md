# Architecture Decision Records

Use ADRs for decisions with long-term architectural consequences.

Recommended format:

```text
docs/development/adr/
├── 0001-server-authoritative-state.md
├── 0002-event-driven-networking.md
├── 0003-data-driven-content.md
└── ...
```

## ADR Template

# ADR-NNNN: Title

## Status

Accepted / Proposed / Superseded

## Context

What problem required a decision?

## Decision

What was chosen?

## Alternatives

What alternatives were considered?

## Consequences

What benefits, costs, and constraints result?

## Date

YYYY-MM-DD
