# Police Stations

Police stations are functional gameplay hubs.

## Potential Areas

- Front Desk
- Briefing Room
- Locker Room
- Armory
- Garage
- Dispatch Room
- Watch Commander Office
- Evidence Room
- Records
- Interview Room
- Booking/Jail
- MDT Terminals

Do not implement every station function in a single class.

Station functionality should be modular and reusable across different departments and stations.
