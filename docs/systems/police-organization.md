# Police Organization

## Organizational Model

MPRP uses a configurable hierarchy:

```text
Department
└── Bureau
    └── Division
        └── Station
            └── Watch
                └── Beat
                    └── Unit
                        └── Officer(s)
```

The initial reference is LAPD-style organization.

The model must remain configurable for other departments such as CHP, LASD, or fictional departments.

## Core Concepts

- Department
- Bureau
- Division
- Station
- Watch
- Beat
- Officer
- Rank
- Assignment
- Unit

## Example

```text
9A21
Valley Division
Watch II
Beat 0913
```

Organizational configuration should be data-driven where practical.
