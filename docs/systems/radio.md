# Radio System

## Features

- Push-to-talk
- Channels
- Transmission state
- Volume
- Squelch
- Priority traffic
- Emergency traffic

## Multiplayer

Radio transmissions are network events.

The server validates and distributes authorized transmissions.

## Singleplayer

Singleplayer provides the radio device and UI but does not require fake human radio participants.

## Priority

Emergency traffic must be able to override ordinary radio traffic.
