# Roles and Permissions

MPRP uses its own permission model rather than treating Minecraft OP status as the gameplay permission system.

## Roles

Possible roles include:

- Police Officer
- Dispatcher
- Supervisor
- Command
- Records
- Evidence Technician
- Crime Analyst
- Forensic Technician
- Property Clerk
- Civilian Staff

## Principles

Permissions should be explicit.

Examples:

- Dispatch calls
- Assign units
- Access CAD
- Approve reports
- Access evidence
- Access armory
- Modify department configuration

Do not scatter permission checks as arbitrary player-name or OP checks throughout the codebase.
